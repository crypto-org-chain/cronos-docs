# 📃 Token Contracts

This guide uses examples from the  `cronos-contract-boilerplate` repository. Please refer to the `README.md` file for more details.

The repo provides the same ERC20, ERC721 and ERC1155 example contracts for three toolchains, so you can pick the one that fits your project:

* `foundry/` for Foundry

{% content-ref url="foundry-boilerplate.md" %}
[foundry-boilerplate.md](foundry-boilerplate.md)
{% endcontent-ref %}

* `hardhat/v3/` for Hardhat 3 (`viem` + `Hardhat Ignition`)

{% content-ref url="hardhat-3-boilerplate.md" %}
[hardhat-3-boilerplate.md](hardhat-3-boilerplate.md)
{% endcontent-ref %}

* `hardhat/v2/` for Hardhat 2 (`ethers` + `TypeScript`)

{% content-ref url="hardhat-2-boilerplate.md" %}
[hardhat-2-boilerplate.md](hardhat-2-boilerplate.md)
{% endcontent-ref %}

{% hint style="info" %}
Hardhat 2 is reaching end of life and is being replaced by Hardhat 3. It will keep getting bug and security fixes until mid 2027, but new projects should use Hardhat 3 and Foundry.
{% endhint %}
