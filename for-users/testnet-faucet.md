# 🚰 Testnet Faucet

### Testnet Faucets

* To interact with the blockchain, simply use the [test-token faucet](https://faucet.cronos.com/) to obtain test CRO tokens for performing transactions on the **Cronos** testnet.
* Users can use the [faucet](https://faucet.cronos.com/) to obtain test tokens, please note that you would need a Ethereum type address `0x...` that can be obtained by [Using metamask](metamask.md#using-metamask-on-cronos-testnet).

{% hint style="info" %}
In case you have reached the daily limit on faucet , you can simply send a message on [Discord](https://discord.gg/pahqHz26q4) #request-tcro-cronos channel , stating who you are and your `0x...` address.
{% endhint %}
